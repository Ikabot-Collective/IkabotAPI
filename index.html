This page generates a blackbox payload from your current browser. It includes the blackbox token, user-agent, locale, and timezone reported by this browser. This page does not ask for your Gameforge password.

The token is generated by Gameforge's browser script hosted at https://gameforge.com/tra/game1.js.

The token can include signals such as:
  • The current date and time
  • The browser version and user-agent
  • The host operating system
  • Fonts available for rendering
  • Display device and graphics information
  • Browser window size
